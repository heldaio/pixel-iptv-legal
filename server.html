InstalarSet up

Do download ao primeiro programa gravado.From download to your first recording.

01

Instala e abreInstall and open

Abre o ficheiro descarregado, copia o Pixel Server para a pasta Aplicações e abre-o. Aparece na barra de menus, no canto de cima do ecrã.

No menu, em Definições, escolhe a pasta das gravações e se o Pixel Server abre ao iniciar sessão.

Open the downloaded file, copy Pixel Server to the Applications folder and open it. It appears in the menu bar, at the top of the screen.

In its menu, under Settings, choose the recordings folder and whether Pixel Server opens at login.

02

Pede um códigoGet a code

No menu do Pixel Server, escolhe «Emparelhar um aparelho…». Aparece um código de 6 algarismos, válido durante alguns minutos.

In Pixel Server’s menu, choose “Pair a device…”. A 6-digit code appears, valid for a few minutes.

03

Emparelha na appPair in the app

Na Pixel IPTV: Definições → Gravação → Pixel Server. Toca em «Emparelhar» ao lado do Mac e escreve o código.

Deixa a tampa aberta e o Mac ligado à corrente: a dormir, o Mac não grava.

In Pixel IPTV: Settings → Recording → Pixel Server. Tap “Pair” next to the Mac and type the code.

Keep the lid open and the Mac plugged in: asleep, the Mac doesn’t record.

01

InstalaInstall

Abre o instalador do teu PC. Pede autorização de administrador e pergunta onde guardar as gravações: por omissão, C:\ProgramData\Pixel Server\Recordings. Escolhe um disco deste PC com espaço; uma pasta de rede não serve.

Open the installer for your PC. It asks for administrator permission and where to keep the recordings: by default, C:\ProgramData\Pixel Server\Recordings. Pick a disk in this PC with room to spare; a network folder won’t do.

02

Abre a página de gestãoOpen the admin page

No fim, o instalador mostra o código de configuração e abre a página de gestão (http://localhost:8790/admin). Escreve o código e escolhe uma palavra-passe.

Também a abres pelo menu Iniciar, em «Pixel Server – Gestão».

At the end, the installer shows the setup code and opens the admin page (http://localhost:8790/admin). Type the code and choose a password.

You can also open it from the Start menu, under “Pixel Server – Admin”.

03

Emparelha na appPair in the app

Clica no ícone do Pixel Server na área de notificação e escolhe «Emparelhar um aparelho…». Na Pixel IPTV, em Definições → Gravação → Pixel Server, toca em «Emparelhar» e escreve o código, ou aponta a câmara para o QR.

A rede de casa tem de estar marcada como privada no Windows.

Click the Pixel Server icon in the notification area and choose “Pair a device…”. In Pixel IPTV, under Settings → Recording → Pixel Server, tap “Pair” and type the code, or point the camera at the QR code.

Your home network must be set to private in Windows.

01

Arranca o servidorStart the server

No Linux, o comando de instalação já o deixa a correr. Num NAS ou com o Docker: docker compose up -d na pasta do ficheiro compose.

O servidor nunca corre como root.

On Linux, the install command leaves it running. On a NAS or with Docker: docker compose up -d in the compose file’s folder.

The server never runs as root.

02

Abre a página de gestãoOpen the admin page

O código de configuração aparece no fim da instalação no Linux; com o Docker, está no registo: docker logs pixel-server. Abre http://<endereço>:8790/admin num navegador da rede de casa, escreve o código e escolhe uma palavra-passe (8 caracteres ou mais).

The setup code appears at the end of the Linux install; with Docker, it is in the log: docker logs pixel-server. Open http://<address>:8790/admin in a browser on your home network, type the code and choose a password (8 characters or more).

03

Emparelha na appPair in the app

Na página de gestão, escolhe «Emparelhar um aparelho…»: aparecem o código e o QR, válidos durante 5 minutos. Na Pixel IPTV, em Definições → Gravação → Pixel Server, toca em «Emparelhar» ao lado do servidor, usa «Adicionar pelo endereço» (por exemplo 192.168.1.50:8790) ou lê o QR.

On the admin page, choose “Pair a device…”: the code and QR code appear, valid for 5 minutes. In Pixel IPTV, under Settings → Recording → Pixel Server, tap “Pair” next to the server, use “Add by address” (for example 192.168.1.50:8790) or scan the QR code.

Bom saberGood to know

Antes de começaresBefore you start

Gratuito; programar é ProFree; scheduling is Pro

O Pixel Server é gratuito. Programar gravações a partir da Pixel IPTV faz parte do Pixel IPTV Pro.

Pixel Server is free. Scheduling recordings from Pixel IPTV is part of Pixel IPTV Pro.

Ligado à hora da gravaçãoOn when the recording starts

O computador tem de estar ligado quando uma gravação começa. No Mac e no Windows, o Pixel Server não o deixa adormecer sozinho enquanto há gravações marcadas.

The computer must be on when a recording starts. On Mac and Windows, Pixel Server keeps it from going to sleep while recordings are due.

Fora de casaAway from home

Com o Mac, programas de qualquer lado: os pedidos chegam pelo teu iCloud privado, com o endereço do canal cifrado. Com Windows, Linux ou NAS, usa uma VPN para a rede de casa (Tailscale ou WireGuard).

Nunca reencaminhes a porta 8790 no router. As gravações veem-se na rede de casa.

With the Mac, schedule from anywhere: requests reach it through your private iCloud, with the channel’s address encrypted. With Windows, Linux or a NAS, use a VPN into your home network (Tailscale or WireGuard).

Never forward port 8790 on your router. Recordings play on your home network.

Um endereço fixoA fixed address

No router, cria uma reserva de DHCP para o computador do servidor. Assim o endereço não muda e a app encontra-o sempre.

In your router, create a DHCP reservation for the server’s computer. That way its address never changes and the app always finds it.

Versões levesLight versions

Enquanto grava, o servidor pode fazer cópias de 360p e 540p que começam depressa e passam em redes lentas. O Mac usa o seu codificador; nos outros é preciso o codificador de vídeo de uma GPU (Intel, AMD, NVIDIA ou, no Windows, outras pelo Media Foundation).

While recording, the server can make 360p and 540p copies that start fast and play on slow networks. The Mac uses its own encoder; elsewhere it needs a GPU’s video encoder (Intel, AMD, NVIDIA or, on Windows, others through Media Foundation).

Tudo fica em tua casaEverything stays at home

As gravações são ficheiros normais (.ts e .mp4) no teu disco. Nada passa pelos nossos servidores, e o servidor grava só os canais da tua própria lista.

Recordings are ordinary files (.ts and .mp4) on your disk. Nothing goes through our servers, and the server only records channels from your own playlist.
